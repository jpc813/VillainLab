# Redemption arc analysis

Mirrors the episode's criticism that history-heavy scoring can't see change.

## Steps
1. Split the evidence file into **Then** (before the turning point) and **Now** (after).
2. Score the eight themes twice: once on Then-evidence only, once on Now-evidence only.
3. Note that **Track Record** can never go down: past acts stay past acts. Show how much it alone props up the "Now" index.
4. Write a short verdict: changed, partly changed, or unchanged (or a fall instead of a redemption).

## Output
```json
{"then": {"scores": {}, "index": 0}, "now": {"scores": {}, "index": 0}, "track_record_effect": "", "verdict": ""}
```
