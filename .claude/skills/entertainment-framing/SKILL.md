# Entertainment framing

## Always
- Add: **"For entertainment only, not a diagnosis."**
- Talk about *characters*, *patterns* and *trait themes*.
- Keep the tone curious and playful, never cruel.

## Never
- "X is a psychopath / sociopath / narcissist" as a clinical statement. Prefer "X's pattern leans toward the cold-predator end of the Dark Triad."
- "Diagnosis," "clinical," "assessment," "you have," "disorder" in results.
- PCL-R item names or the 0-40 scale as if the app used them.
- Advice about real people.

## Self-quiz specifics
- Results are about the quiz-taker only and should land kindly (e.g., "Too neurotic to be a psychopath. Congratulations, you have a conscience.").
- If someone seems genuinely worried about their mental health, point gently to a professional; don't analyze them.
