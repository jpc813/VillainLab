# Source citation

## Steps
1. Prefer primary sources: journal pages, official docs, the episode page.
2. Summarize in your own words. Quotes only if essential, under 15 words, attributed.
3. Add every new link to `docs/sources.md` under the right heading.
4. The Resources page is generated from `docs/sources.md`; keep both in sync.
5. Private people from the episode always use the fictitious names in `docs/09-about-page-story.md`.

## Format
`- Author (Year). Title. *Venue*: https://...`
